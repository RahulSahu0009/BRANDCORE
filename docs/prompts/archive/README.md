# docs/prompts/archive/

These are **historical session prompts** used during the BRANDCORE bootstrap and M1 POC phases.
They are preserved as an audit trail only.

**They are not active project instructions.** The authoritative project instructions are:

- `CLAUDE.md` — session entry point
- `RULES.md` — non-negotiable implementation rules
- `docs/ARCHITECTURE.md` — system design
- `docs/EXECUTION_PLAN.md` — milestone plan
- `TASKS.md` / `MEMORY.md` — living work board and state

| File | Phase | Purpose |
|------|-------|---------|
| `BRANDCORE_CLAUDE_CODE_BUILD_PROMPT.json` | M0 bootstrap | Initial repository scaffold prompt |
| `BRANDCORE_M1_CLOUDFLARE_RUNTIME_POC_PROMPT.json` | M1 POC | Cloudflare runtime proof-of-concept prompt |
| `BRANDCORE_PRE_GITHUB_CLEANUP_PROMPT.json` | Pre-GitHub cleanup | Repository cleanup and organization prompt |
